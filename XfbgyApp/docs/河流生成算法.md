# 河流生成算法

## 算法概述

本算法用于在六角格地图上生成一条自然流动的河流。河流从地图四条边缘（x=0、x=X、y=0、y=Y）之一进入，沿蛇形路径穿越地图，直到触碰另一条地图边界停止。

## 算法步骤

### 步骤1：选择河流入口

河流可以从地图的四个方向进入，选择方式如下：

| 入口边缘 | 入口边编号 | 入口边方向 | 流动方向 | 河流类型 |
|---------|-----------|-----------|---------|---------|
| y=0（顶部） | 1号边 (idx0) | 顶边 | 顺时针 | 纵向河流（从上往下） |
| y=Y（底部） | 4号边 (idx3) | 底边 | 顺时针 | 纵向河流（从下往上） |
| x=0（左侧） | 4号边 (idx3) | 底边 | 逆时针 | 横向河流（从左往右） |
| x=X（右侧） | 1号边 (idx0) | 顶边 | 逆时针 | 横向河流（从右往左） |

**入口选择规则：**
1. 从四条边缘中随机选择一条作为入口边缘
2. 在选中的边缘上随机选择一个有效格子作为入口格子
3. 根据入口边缘确定入口边编号和流动方向（见上表）

**示例：**
- 选择 y=0 边缘：河流从1号边(顶边)流入，顺时针流动，生成纵向河流
- 选择 y=Y 边缘：河流从4号边(底边)流入，顺时针流动，生成纵向河流
- 选择 x=0 边缘：河流从4号边(底边)流入，逆时针流动，生成横向河流
- 选择 x=X 边缘：河流从1号边(顶边)流入，逆时针流动，生成横向河流

### 步骤2：按固定概率选择出口

对于当前格子，河流从入口边流入后，需要从另一条边流出。

1. **排除入口边本身**——河流不能原路返回
2. **排除会形成闭环的边**——即出口边对应的邻居格子已被河流访问过
3. **排除沿流动方向第5条边（入口边的对边）**——该边概率为0，始终不可选
4. 对剩余的候选出口边，根据 **沿流动方向的位置** 分配固定概率

#### 顺时针流动的概率分配

从入口边 n 开始，沿顺时针方向（边编号递增），各候选边的概率：

| 顺时针位置 | 概率 | 说明 |
|-----------|------|------|
| 第1条边 | 0.1 | 紧邻入口边的顺时针方向 |
| 第2条边 | 0.4 | |
| 第3条边 | 0.4 | |
| 第4条边 | 0.1 | |
| 第5条边 | 0.0 | 入口边的对边，始终排除 |

**示例**：入口=3号边(idx2)，顺时针方向的边依次为 4(idx3)→5(idx4)→6(idx5)→1(idx0)→2(idx1)

| 候选边 | 顺时针位置 | 概率 |
|--------|-----------|------|
| 4号边 | 第1条 | 0.1 |
| 5号边 | 第2条 | 0.4 |
| 6号边 | 第3条 | 0.4 |
| 1号边 | 第4条 | 0.1 |
| 2号边 | 第5条 | 0（排除） |

#### 逆时针流动的概率分配

从入口边 n 开始，沿逆时针方向（边编号递减），各候选边的概率：

| 逆时针位置 | 概率 | 说明 |
|-----------|------|------|
| 第1条边 | 0.1 | 紧邻入口边的逆时针方向 |
| 第2条边 | 0.4 | |
| 第3条边 | 0.4 | |
| 第4条边 | 0.1 | |
| 第5条边 | 0.0 | 入口边的对边，始终排除 |

**示例**：入口=3号边(idx2)，逆时针方向的边依次为 2(idx1)→1(idx0)→6(idx5)→5(idx4)→4(idx3)

| 候选边 | 逆时针位置 | 概率 |
|--------|-----------|------|
| 2号边 | 第1条 | 0.1 |
| 1号边 | 第2条 | 0.4 |
| 6号边 | 第3条 | 0.4 |
| 5号边 | 第4条 | 0.1 |
| 4号边 | 第5条 | 0（排除） |

#### 闭环排除后的归一化

当某些候选边因闭环被排除后，将剩余边的概率归一化（按比例缩放使总和为1.0）。

#### 初始区域特殊概率

为了防止河流过短，在河流入口附近的初始区域内，使用特殊的概率分配：

- **纵向河流（顶部/底部入口）**：在入口侧的前两行中
  - 顶部入口：当前格子 y=0 或 y=1
  - 底部入口：当前格子 y=Y-1 或 y=Y-2
- **横向河流（左侧/右侧入口）**：在入口侧的前两列中
  - 左侧入口：当前格子 x=0 或 x=1
  - 右侧入口：当前格子 x=X-1 或 x=X-2

在初始区域内，概率分配替换为：

**顺时针流动（初始区域）：**

| 顺时针位置 | 概率 | 说明 |
|-----------|------|------|
| 第1条边 | 0 | |
| 第2条边 | 0.5 | |
| 第3条边 | 0.5 | |
| 第4条边 | 0 | |
| 第5条边 | 0.0 | 入口边的对边，始终排除 |

**逆时针流动（初始区域）：**

| 逆时针位置 | 概率 | 说明 |
|-----------|------|------|
| 第1条边 | 0 | |
| 第2条边 | 0.5 | |
| 第3条边 | 0.5 | |
| 第4条边 | 0 | |
| 第5条边 | 0.0 | 入口边的对边，始终排除 |

即初始区域内只允许第2、第3条边作为出口（各50%概率），迫使河流向地图深处流动，避免过早转向出口侧。

### 步骤3：标记从入口到出口的所有边

确定出口边后，需要将 **从入口边到出口边之间沿流动方向的所有边** 都标记为有河流。

**关键规则**：河流在格子内部沿流动方向覆盖从入口到出口的连续边，而非仅标记入口和出口两条边。

#### 顺时针流动

从入口边开始，沿顺时针方向（边编号递增），直到出口边，路径上所有边都标记河流。

```
示例：入口=1号边(idx0)，出口=3号边(idx2)，顺时针
河流边：1→2→3（idx 0,1,2），全部标记 hasRiver=true
```

#### 逆时针流动

从入口边开始，沿逆时针方向（边编号递减），直到出口边，路径上所有边都标记河流。

```
示例：入口=6号边(idx5)，出口=2号边(idx1)，逆时针
河流边：6→5→4→3→2（idx 5,4,3,2,1），全部标记 hasRiver=true
```

### 步骤4：找到出口边的邻居

找到与出口边相邻的邻居格子。

- 出口边 `exitDir` 对应的邻居坐标：根据奇偶行和方向计算偏移
- 邻居格子的入口边：`entryDir = (exitDir + 3) % 6`（对面的边）

### 步骤5：切换流动方向

进入邻居格子后，切换流动方向：

- 如果上一步是 **顺时针** 流动，则改为 **逆时针** 流动
- 如果上一步是 **逆时针** 流动，则改为 **顺时针** 流动

### 步骤6：重复步骤2~5

在新格子中重复步骤2~5，流动方向交替切换。

### 步骤7：停止条件

当满足以下任一条件时，河流停止：

1. **边界到达**：出口边对应的邻居在地图边界外
2. **无候选出口**：当前格子没有有效的候选出口边（所有非入口边要么会导致闭环，要么邻居在边界外）
3. **概率结束**：当河流长度 n > 10 时，每一步以概率 P = 0.3 + 0.02 × (n - 10) 提前结束河流生成。其中 n 为当前河流已经过的格子数（即河流长度），P 为在该长度时河流结束生成的概率。

当出口边在地图边界时，仍然标记该边为有河流（河流流出地图），然后停止。

**概率结束说明**：
- 当 n = 11 时，P = 0.3 + 0.02 × 1 = 0.32
- 当 n = 15 时，P = 0.3 + 0.02 × 5 = 0.40
- 当 n = 20 时，P = 0.3 + 0.02 × 10 = 0.50
- 当 n = 35 时，P = 0.3 + 0.02 × 25 = 0.80（理论上限，实际 P 封顶为 1.0）
- 即 P = min(1.0, 0.3 + 0.02 × (n - 10))

## 算法伪代码

```
function generateRiver(map):
    // 步骤1：选择入口（从四个方向之一进入）
    border = random(0, 3)  // 0=top, 1=right, 2=bottom, 3=left
    
    if border == 0:  // y=0 顶部
        startCell = random cell in row 0
        entryEdge = 0  // 1号边（顶边）
        flowDirection = CLOCKWISE  // 顺时针
    elif border == 1:  // x=X 右侧
        startCell = random cell in column X-1
        entryEdge = 0  // 1号边（顶边）
        flowDirection = COUNTER_CLOCKWISE  // 逆时针
    elif border == 2:  // y=Y 底部
        startCell = random cell in row Y-1
        entryEdge = 3  // 4号边（底边）
        flowDirection = CLOCKWISE  // 顺时针
    else:  // x=0 左侧
        startCell = random cell in column 0
        entryEdge = 3  // 4号边（底边）
        flowDirection = COUNTER_CLOCKWISE  // 逆时针

    currentCell = startCell
    currentEntry = entryEdge

    // 步骤2：在起始格子选择出口边
    exitEdge = selectExitEdge(currentCell, currentEntry, flowDirection)
    if exitEdge is null: return
    
    // 步骤3：标记从入口到出口沿流动方向的所有边
    markRiverEdges(currentCell, currentEntry, exitEdge, flowDirection)
    
    // 步骤4：获取邻居格子
    neighbor = getNeighbor(currentCell, exitEdge)
    if neighbor is outside map: return
    
    // 主循环
    riverLength = 1  // 河流长度，起始格子为1
    while true:
        // 新格子的入口边是出口边的对面
        nextEntry = (exitEdge + 3) % 6
        
        // 切换流动方向
        nextFlowDirection = toggle(flowDirection)
        
        // 概率结束检查：当河流长度 > 10 时，以概率 P 结束
        riverLength++
        if riverLength > 10:
            P = min(1.0, 0.3 + 0.02 * (riverLength - 10))
            if random() < P:
                break  // 河流概率结束
        
        // 选择出口边
        nextExitEdge = selectExitEdge(neighbor, nextEntry, nextFlowDirection)
        if nextExitEdge is null: break
        
        // 标记河流边
        markRiverEdges(neighbor, nextEntry, nextExitEdge, nextFlowDirection)
        
        // 获取下一个邻居
        nextNeighbor = getNeighbor(neighbor, nextExitEdge)
        if nextNeighbor is outside map: break
        
        // 移动到下一个格子
        currentCell = neighbor
        neighbor = nextNeighbor
        exitEdge = nextExitEdge
        flowDirection = nextFlowDirection

function selectExitEdge(cell, entryEdge, flowDirection, isInInitialZone):
    // 沿流动方向收集候选出口边（位置1~4）
    candidates = []
    for offset in 1..4:
        candidate = (entryEdge + offset) % 6 if flowDirection == CLOCKWISE 
                   else (entryEdge - offset + 6) % 6
        if getNeighbor(cell, candidate) is valid and not mountain/urban:
            candidates.add(candidate)
    
    if candidates is empty: return null
    
    // 按位置分配概率
    if isInInitialZone:
        // 初始区域：位置2→0.5, 3→0.5，其他→0
        weights = [0, 0.5, 0.5, 0]
    else:
        // 正常区域：位置1→0.1, 2→0.4, 3→0.4, 4→0.1
        weights = [0.1, 0.4, 0.4, 0.1]
    return weightedRandomSelect(candidates, weights)

function markRiverEdges(cell, entryEdge, exitEdge, flowDirection):
    current = entryEdge
    while true:
        cell.setRiver(current, true)  // 设置边为河流
        if current == exitEdge: break
        current = (current + 1) % 6 if flowDirection == CLOCKWISE 
                  else (current - 1 + 6) % 6
```

## 边编号与邻居偏移

### 边编号规则（顶边为1号边，顺时针编号）

| 编号 | 方向索引 | 方向名 | 说明 |
|------|---------|--------|------|
| 1号边 | 0 | 顶边 | 六边形顶部边 |
| 2号边 | 1 | 右上 | 顺时针下一条边 |
| 3号边 | 2 | 右下 | 顺时针下一条边 |
| 4号边 | 3 | 底边 | 六边形底部边 |
| 5号边 | 4 | 左下 | 顺时针下一条边 |
| 6号边 | 5 | 左上 | 顺时针下一条边 |

### 邻居偏移（odd-r偏移坐标）

**偶数行（y % 2 == 0）：**

| 方向 | 偏移(dx, dy) | 说明 |
|------|-------------|------|
| 0 (顶边) | (0, -1) | 上方邻居 |
| 1 (右上) | (1, 0) | 右侧邻居 |
| 2 (右下) | (0, 1) | 右下方邻居 |
| 3 (底边) | (-1, 1) | 左下方邻居 |
| 4 (左下) | (-1, 0) | 左侧邻居 |
| 5 (左上) | (-1, -1) | 左上方邻居 |

**奇数行（y % 2 == 1）：**

| 方向 | 偏移(dx, dy) | 说明 |
|------|-------------|------|
| 0 (顶边) | (1, -1) | 右上方邻居 |
| 1 (右上) | (1, 0) | 右侧邻居 |
| 2 (右下) | (1, 1) | 右下方邻居 |
| 3 (底边) | (0, 1) | 下方邻居 |
| 4 (左下) | (-1, 0) | 左侧邻居 |
| 5 (左上) | (0, -1) | 上方邻居 |

## 示例

假设 5×5 地图：

**示例1：纵向河流（从顶部 y=0 进入）**
```
1. 选择 y=0 边缘，假设选中 (2,0) 格子
2. 入口边 = 1号边(idx0)（顶边），顺时针流动
3. 排除对边4号边(idx3)
4. 初始区域（y=0,0≤1）：候选出口仅位置2和3，即2号(0.5), 5号(0.5)
5. 假设选中2号边(idx2)（右下方向，概率0.5）
6. 标记从入口到出口的所有边：0→1→2号边(idx 0,1,2) 全部 hasRiver=true
7. 邻居为 (2,1)，入口边 = (2+3)%6 = 5号边
8. 切换为逆时针流动，继续...
9. y=1仍在初始区域，继续使用初始区域概率
```

**示例2：横向河流（从左侧 x=0 进入）**
```
1. 选择 x=0 边缘，假设选中 (0,2) 格子
2. 入口边 = 4号边(idx3)（底边），逆时针流动
3. 排除对边1号边(idx0)
4. 初始区域（x=0,0≤1）：候选出口仅位置2和3
5. 假设选中位置3的出口边
6. 标记从入口到出口沿逆时针方向的所有边
7. 邻居入口边 = 出口边的对面边
8. 切换为顺时针流动，继续...
9. x=1仍在初始区域，继续使用初始区域概率
```

**河流持续流动直到满足停止条件：到达对侧边缘（x=X、y=Y 或地图边界）、无有效候选出口、或概率结束。**
