# 河流生成算法

## 算法概述

本算法用于在六角格地图上生成一条自然流动的河流。河流从地图第一行的某个格子的顶边（1号边）进入，沿蛇形路径穿越地图，直到触碰地图边界停止。

## 算法步骤

### 步骤1：选择河流入口

选择第一行（y=0）任意一个格子，将该格子的 **1号边**（顶边，direction=0）作为河流入口。

- 河流从地图外部通过1号边流入该格子

### 步骤2：按固定概率选择出口

对于当前格子，河流从入口边流入后，需要从另一条边流出。

1. **排除入口边本身**——河流不能原路返回
2. **排除会形成闭环的边**——即出口边对应的邻居格子已被河流访问过
3. **排除沿流动方向第5条边（入口边的对边）**——该边概率为0，始终不可选
4. 对剩余的候选出口边，根据 **沿流动方向的位置** 分配固定概率

#### 顺时针流动的概率分配

从入口边 n 开始，沿顺时针方向（边编号递增），各候选边的概率：

| 顺时针位置 | 概率 | 说明 |
|-----------|------|------|
| 第1条边 | 0.1 | 紧邻入口边的顺时针方向 |
| 第2条边 | 0.4 | |
| 第3条边 | 0.4 | |
| 第4条边 | 0.1 | |
| 第5条边 | 0.0 | 入口边的对边，始终排除 |

**示例**：入口=3号边(idx2)，顺时针方向的边依次为 4(idx3)→5(idx4)→6(idx5)→1(idx0)→2(idx1)

| 候选边 | 顺时针位置 | 概率 |
|--------|-----------|------|
| 4号边 | 第1条 | 0.1 |
| 5号边 | 第2条 | 0.4 |
| 6号边 | 第3条 | 0.4 |
| 1号边 | 第4条 | 0.1 |
| 2号边 | 第5条 | 0（排除） |

#### 逆时针流动的概率分配

从入口边 n 开始，沿逆时针方向（边编号递减），各候选边的概率：

| 逆时针位置 | 概率 | 说明 |
|-----------|------|------|
| 第1条边 | 0.1 | 紧邻入口边的逆时针方向 |
| 第2条边 | 0.4 | |
| 第3条边 | 0.4 | |
| 第4条边 | 0.1 | |
| 第5条边 | 0.0 | 入口边的对边，始终排除 |

**示例**：入口=3号边(idx2)，逆时针方向的边依次为 2(idx1)→1(idx0)→6(idx5)→5(idx4)→4(idx3)

| 候选边 | 逆时针位置 | 概率 |
|--------|-----------|------|
| 2号边 | 第1条 | 0.1 |
| 1号边 | 第2条 | 0.4 |
| 6号边 | 第3条 | 0.4 |
| 5号边 | 第4条 | 0.1 |
| 4号边 | 第5条 | 0（排除） |

#### 闭环排除后的归一化

当某些候选边因闭环被排除后，将剩余边的概率归一化（按比例缩放使总和为1.0）。

### 步骤3：标记从入口到出口的所有边

确定出口边后，需要将 **从入口边到出口边之间沿流动方向的所有边** 都标记为有河流。

**关键规则**：河流在格子内部沿流动方向覆盖从入口到出口的连续边，而非仅标记入口和出口两条边。

#### 顺时针流动

从入口边开始，沿顺时针方向（边编号递增），直到出口边，路径上所有边都标记河流。

```
示例：入口=1号边(idx0)，出口=3号边(idx2)，顺时针
河流边：1→2→3（idx 0,1,2），全部标记 hasRiver=true
```

#### 逆时针流动

从入口边开始，沿逆时针方向（边编号递减），直到出口边，路径上所有边都标记河流。

```
示例：入口=6号边(idx5)，出口=2号边(idx1)，逆时针
河流边：6→5→4→3→2（idx 5,4,3,2,1），全部标记 hasRiver=true
```

### 步骤4：找到出口边的邻居

找到与出口边相邻的邻居格子。

- 出口边 `exitDir` 对应的邻居坐标：根据奇偶行和方向计算偏移
- 邻居格子的入口边：`entryDir = (exitDir + 3) % 6`（对面的边）

### 步骤5：切换流动方向

进入邻居格子后，切换流动方向：

- 如果上一步是 **顺时针** 流动，则改为 **逆时针** 流动
- 如果上一步是 **逆时针** 流动，则改为 **顺时针** 流动

### 步骤6：重复步骤2~5

在新格子中重复步骤2~5，流动方向交替切换。

### 步骤7：边界停止条件

当满足以下任一条件时，河流停止：

1. 出口边对应的邻居在地图边界外
2. 当前格子没有有效的候选出口边（所有非入口边要么会导致闭环，要么邻居在边界外）

当出口边在地图边界时，仍然标记该边为有河流（河流流出地图），然后停止。

## 算法伪代码

```
function generateRiver(map):
    // 步骤1：选择入口
    startCell = random cell in row 0
    entryEdge = 0  // 1号边（顶边）

    currentCell = startCell
    currentEntry = entryEdge
    flowDirection = CLOCKWISE
    visitedCells = {startCell}

    while true:
        // 步骤2：选择出口（固定概率）
        candidates = getNonLoopEdges(currentCell, currentEntry, visitedCells)
        // 排除沿流动方向第5条边（对边）
        oppositeEdge = (currentEntry + 3) % 6
        candidates.remove(oppositeEdge)

        if candidates is empty:
            break  // 无有效出口，停止

        exitEdge = selectByFixedProbability(candidates, currentEntry, flowDirection)

        // 步骤3：标记从入口到出口的所有边
        riverEdges = getEdgesAlongFlow(currentEntry, exitEdge, flowDirection)
        for edge in riverEdges:
            markEdge(currentCell, edge, hasRiver=true)

        // 步骤4：找到邻居
        neighbor = getNeighbor(currentCell, exitEdge)
        if neighbor is outside map:
            break  // 触碰边界，停止

        neighborEntry = (exitEdge + 3) % 6

        // 步骤5：切换方向
        flowDirection = toggle(flowDirection)

        // 步骤6：继续
        currentCell = neighbor
        currentEntry = neighborEntry
        visitedCells.add(neighbor)

function selectByFixedProbability(candidates, entryEdge, flowDirection):
    // 计算每条候选边沿流动方向的位置
    weights = []
    for e in candidates:
        position = getPositionAlongFlow(entryEdge, e, flowDirection)  // 1~4
        weight = [0.0, 0.1, 0.4, 0.4, 0.1][position]  // 位置1→0.1, 2→0.4, 3→0.4, 4→0.1
        weights.add(weight)

    // 归一化
    total = weights.sum()
    weights = weights.map { it / total }

    // 加权随机选择
    roll = random(0, 1)
    cumulative = 0
    for i in candidates.indices:
        cumulative += weights[i]
        if roll <= cumulative:
            return candidates[i]
    return candidates.last()

function getPositionAlongFlow(entryEdge, candidateEdge, flowDirection):
    // 计算候选边沿流动方向的位置（1~5）
    if flowDirection == CLOCKWISE:
        steps = (candidateEdge - entryEdge + 6) % 6  // 顺时针步数
    else:
        steps = (entryEdge - candidateEdge + 6) % 6  // 逆时针步数
    return steps  // 范围 1~5（5=对边，已排除）

function getEdgesAlongFlow(entryDir, exitDir, flowDirection):
    edges = []
    current = entryDir
    while true:
        edges.add(current)
        if current == exitDir:
            break
        if flowDirection == CLOCKWISE:
            current = (current + 1) % 6   // 顺时针递增
        else:
            current = (current + 5) % 6   // 逆时针递减
    return edges
```

## 边编号与邻居偏移

### 边编号规则（顶边为1号边，顺时针编号）

| 编号 | 方向索引 | 方向名 | 说明 |
|------|---------|--------|------|
| 1号边 | 0 | 顶边 | 六边形顶部边 |
| 2号边 | 1 | 右上 | 顺时针下一条边 |
| 3号边 | 2 | 右下 | 顺时针下一条边 |
| 4号边 | 3 | 底边 | 六边形底部边 |
| 5号边 | 4 | 左下 | 顺时针下一条边 |
| 6号边 | 5 | 左上 | 顺时针下一条边 |

### 邻居偏移（odd-r偏移坐标）

**偶数行（y % 2 == 0）：**

| 方向 | 偏移(dx, dy) | 说明 |
|------|-------------|------|
| 0 (顶边) | (0, -1) | 上方邻居 |
| 1 (右上) | (1, 0) | 右侧邻居 |
| 2 (右下) | (0, 1) | 右下方邻居 |
| 3 (底边) | (-1, 1) | 左下方邻居 |
| 4 (左下) | (-1, 0) | 左侧邻居 |
| 5 (左上) | (-1, -1) | 左上方邻居 |

**奇数行（y % 2 == 1）：**

| 方向 | 偏移(dx, dy) | 说明 |
|------|-------------|------|
| 0 (顶边) | (1, -1) | 右上方邻居 |
| 1 (右上) | (1, 0) | 右侧邻居 |
| 2 (右下) | (1, 1) | 右下方邻居 |
| 3 (底边) | (0, 1) | 下方邻居 |
| 4 (左下) | (-1, 0) | 左侧邻居 |
| 5 (左上) | (0, -1) | 上方邻居 |

## 示例

假设 5×5 地图：

```
1. 选择 (2,0) 的1号边(idx0)作为入口
2. 顺时针流动，排除对边4号边(idx3)
3. 候选出口：2号(0.1), 3号(0.4), 5号(0.4), 6号(0.1)
4. 假设选中3号边(idx2)（右下方向，概率0.4）
5. 标记从入口到出口的所有边：1→2→3号边(idx 0,1,2) 全部 hasRiver=true
6. 邻居为 (2,1)，入口边 = (2+3)%6 = 5号边(idx5)（即6号边）
7. 切换为逆时针流动
8. 在 (2,1) 中，排除对边3号边(idx2)和已访问格子的边
9. 逆时针候选：5号(0.1), 4号(0.4), 3号排除, 2号(0.4), 1号(0.1)→排除已访问后归一化
10. 假设选中2号边(idx1)（右上方向）
11. 标记从入口到出口的所有边：6→5→4→3→2号边(idx 5,4,3,2,1) 全部 hasRiver=true
12. 邻居为 (3,1)，入口边 = (1+3)%6 = 4号边(idx4)（即5号边）
13. 切换为顺时针流动
14. 继续交替...
15. 直到出口边对应邻居在地图外，停止
```
