# 建筑群地图生成算法

## 定义

- **m**：地图总格子数 (m = n × n)
- **n**：地图边长
- **聚团**：2-3格相邻的建筑群格子
- **聚团集**：聚团占有的坐标集合
- **空图集**：未放置任何地形的格子坐标集合（初始为全部格子）
- **离散建筑集**：单个的建筑群格子的坐标集合

## 生成算法

### 步骤1：放置聚团1
在 x 坐标 < (1/6)n，y 坐标任意，随机选一个位置作为聚团1，并加入"聚团集"。

### 步骤2：计算禁入区域
从"空图集"中移除"聚团集"的坐标，然后找出地图上离"聚团集"里所有聚团的距离都 < (2/3)n 的坐标点，移出"空图集"。

### 步骤3：放置聚团2
在"空图集"中，随机一个坐标，作为聚团2，并加入"聚团集"，然后从"空图集"中移除与之相邻的所有格子的坐标（遍历"聚团集"和"离散建筑集"的所有坐标点的邻居）。

### 步骤4：计算聚团总数
计算目前"聚团集"中的聚团总数，设为 x。

### 步骤5：生成离散建筑集
在"空图集"中，随机选取一个格子，加入"离散建筑集"，然后再把它和它的邻居的坐标，从"空图集"中移除（遍历"聚团集"和"离散建筑集"的所有坐标点的邻居）；重复这个动作 x×5 次。

### 步骤6：检查终止条件
如果"聚团集"和"离散建筑集"中的总坐标数 >= (m×10%) - 8 或"空图集"为空，则跳到步骤10；否则跳到步骤7。

### 步骤7：生成新聚团
从"空图集"中随机一个坐标，生成一个聚团，放入"聚团集"，并从"空图集"中移除这个聚团的坐标和它的所有邻居的坐标（遍历"聚团集"和"离散建筑集"的所有坐标点的邻居）；**注意：生成的聚团的所有坐标都必须还在空图集中**；如果无法形成"聚团"，跳到步骤8。

### 步骤8：生成新离散建筑
从"空图集"中随机一个坐标，放入"离散建筑集"，并从"空图集"中移除这个"离散建筑"的坐标和它的所有邻居坐标（遍历"聚团集"和"离散建筑集"的所有坐标点的邻居）。

### 步骤9：循环
重复步骤6-9。

### 步骤10：放置建筑群
将"聚团集"和"离散建筑集"中的格子放入地图。

### 步骤11：分配其他地形
剩下的格子按比例分配：
- 60% 平原
- 15% 山地
- 10% 森林
- 5% 高山（必须与山地相邻）

## 邻居移除规则

在所有步骤中，当需要从"空图集"移除"与之相邻的所有格子的坐标"时，需要：
1. 遍历"聚团集"中的所有坐标点
2. 遍历"离散建筑集"中的所有坐标点
3. 将这些坐标点及其所有邻居都从"空图集"中移除

## 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 聚团大小 | 2-3格 | 每个聚团包含的格子数 |
| 聚团1区域 | x < n/6 | 聚团1的生成区域 |
| 禁入区域距离 | < 2n/3 | 距离聚团的最小距离 |
| 离散:聚团比例 | 5:1 | 每个聚团对应5个离散格子 |
| 建筑群总比例 | 10% - 8 | 聚团+离散建筑占总格子数（减去8的容差） |
