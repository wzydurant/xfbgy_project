# 地图建筑群生成算法

## 术语定义

| 术语 | 定义 |
|------|------|
| m | 地图总格子数 |
| n | 地图边长（取宽高中的较大者） |
| 聚团 | 2-3格相邻的建筑群格子组成的连通块 |
| 聚团集 | 所有聚团占有的坐标集合 |
| 空图集 | 未放置任何建筑群的格子坐标集合（初始为全部格子） |

## 生成算法

### 步骤1：放置聚团1
在 `x < (1/6)n` 的区域（地图左侧1/6区域）随机选一个位置作为聚团1的种子格，然后生长为2-3格的聚团，加入"聚团集"。

### 步骤2：计算禁入区域
从"空图集"中移除"聚团集"的坐标，然后找出地图上**离所有聚团距离都 < (2/3)n** 的坐标点，这些点因为离现有聚团太近而不能用于放置新聚团，也从"空图集"中移除。

**距离计算**：使用六边形曼哈顿距离

### 步骤3：放置聚团2
在更新后的"空图集"中随机选一个坐标，作为聚团2的种子格，生长为2-3格的聚团，加入"聚团集"。

### 步骤4：继续生成聚团
重复以下操作生成新聚团：
- 选取坐标要求：不与"聚团集"中的任何坐标相邻
- 聚团大小：2-3格随机

### 步骤5：检查聚团数量上限
每次生成新聚团后，检查"聚团集"的坐标总数：
- 如果 **聚团集总格子数 ≥ m × 8%**，跳到步骤6
- 否则重复步骤4

### 步骤6：放置聚团到地图
将"聚团集"中的所有聚团格子设置为 `URBAN` 地形。

### 步骤7：放置离散建筑群
在"空图集"中随机均匀分布 **m × 8%** 个离散建筑群格子，要求：
- 离散格子之间互相不相邻（六边形距离 ≥ 2）
- 离散格子不与任何聚团相邻

### 步骤8：放置其他地形
将剩余的格子按以下比例分配：
| 地形 | 比例 |
|------|------|
| 平原 | 60% |
| 山地 | 15% |
| 森林 | 10% |
| 高山 | 5% |

**约束**：高山必须与山地相邻才能存在。如果高山数量不足，补充到山地相邻的格子。

## 距离计算公式

六边形曼哈顿距离（轴向坐标转换后）：
```
dq = |q1 - q2|
dr = |r1 - r2|
ds = |s1 - s2|
distance = max(dq, dr, ds)
```

其中 s = -q - r

## 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 聚团大小 | 2-3格 | 每个聚团包含的格子数 |
| 聚团比例上限 | 8% | 聚团占总格子数的最大比例 |
| 离散格子比例 | 8% | 离散建筑群占总格子数的比例 |
| 聚团间最小距离 | (2/3)n | 新聚团必须离现有聚团足够远 |
| 聚团分布区 | x < (1/6)n | 初始聚团的分布区域 |

## 示例

假设 30×30 地图（m=900）：
- 聚团最多占：900 × 8% = 72格
- 离散建筑群占：900 × 8% = 72格
- 建筑群总计约：144格（16%）

## 流程图

```
开始
  ↓
[步骤1] 在x<(1/6)n区域放置聚团1
  ↓
[步骤2] 计算禁入区域（距聚团<(2/3)n的点）
  ↓
[步骤3] 在空图集中放置聚团2
  ↓
[步骤4] 继续生成聚团（不与聚团集相邻）
  ↓
[步骤5] 聚团集≥m×8%? ─否→ 返回步骤4
  ↓是
[步骤6] 将聚团放入地图
  ↓
[步骤7] 随机分布m×8%离散建筑群
  ↓
[步骤8] 按比例放置平原/山地/森林/高山
  ↓
结束
```
